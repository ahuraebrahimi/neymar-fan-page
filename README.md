## 📖 About

This project is a modern **single-page responsive website** created as a front-end portfolio project and a tribute to one of football's greatest players, **Neymar Jr.**

The website focuses on delivering a premium user experience through smooth animations, interactive sections, modern UI design, and clean semantic code—all built using pure HTML, CSS, and JavaScript.

---

## ✨ Features

- 🎨 Modern UI/UX
- 📱 Fully Responsive Design
- 🧭 Sticky Navigation Bar
- 🍔 Mobile Hamburger Menu
- 🎞️ Animated Hero Section
- 🌊 Floating & Parallax Effects
- 📊 Animated Statistics Counters
- ✨ Scroll Reveal Animations
- 🖼️ Interactive Gallery
- 🔍 Lightbox Image Viewer
- 🗂️ Gallery Filtering
- 📅 Career Timeline
- 💬 Fan Contact Form
- ⚡ Built with Vanilla JavaScript

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/ahuraebrahimi/neymar-fan-page.git
```

Go to the project folder:

```bash
cd neymar-portfolio
```

Open **index.html** in your favorite browser.

No installation or build process is required.
