## 📖 معرفی پروژه

در این پروژه تلاش شده با استفاده از HTML، CSS و JavaScript خالص، یک رابط کاربری مدرن، روان و حرفه‌ای طراحی شود؛ بدون استفاده از هیچ فریمورکی.

## 🚀 نحوه اجرا

ابتدا پروژه را دانلود یا Clone کنید:


سپس وارد پوشه پروژه شوید:

